# SolarScope Dataset Documentation & Provenance

## 1. Overview and Authenticity Statement
All generation telemetry and meteorological observations utilized in the **SolarScope** platform originate from **real-world, operational utility-scale photovoltaic power plants**. No synthetic measurements, simulated generation profiles, or fabricated sensor streams were introduced.

---

## 2. Dataset Provenance and Source

### Original Source
- **Dataset Name:** Solar Power Generation Data
- **Primary Hosting:** Kaggle Public Data Repository / Open Science Mirrors
- **License / Usage Conditions:** CC0: Public Domain (Open data for academic, research, and commercial software analytics)
- **Data Collection Period:** May 15, 2020 00:00:00 to June 17, 2020 23:45:00 (34 consecutive days of high-resolution telemetry)
- **Geographic Location:** Gandhinagar, Gujarat, India (Coordinates: approx. 23.2156° N, 72.6369° E)
- **Time Resolution:** 15-minute intervals (96 telemetry readings per inverter per day)

---

## 3. Monitored Assets & Specifications

### Plant 1: Gandhinagar Solar Park - Plant 1
- **Plant ID:** `4135001`
- **Total Inverters:** 22 central inverters (represented by unique alphanumeric `SOURCE_KEY` identifiers)
- **Nominal Inverter AC Capacity:** 1,410 kW per inverter
- **Total Plant AC Nameplate:** 31.02 MW AC (22 × 1,410 kW)
- **Nominal DC Array Capacity:** ~1,447 kWp per inverter (Total: ~31.8 MWp)
- **DC Measurement Scaling:** The logger records raw DC power scaled by a factor of 10 relative to kW. Standardized to true kW via `DC_POWER / 10.0`.
- **Weather Stations:** 1 localized on-site weather monitoring station recording ambient temperature, module back-of-module temperature, and plane-of-array solar irradiation.

### Plant 2: Gandhinagar Solar Park - Plant 2
- **Plant ID:** `4136001`
- **Total Inverters:** 22 central inverters
- **Nominal Inverter AC Capacity:** 1,385 kW per inverter
- **Total Plant AC Nameplate:** 30.47 MW AC (22 × 1,385 kW)
- **Nominal DC Array Capacity:** ~1,420 kWp per inverter (Total: ~31.2 MWp)
- **DC Measurement Scaling:** Raw DC power is recorded directly in true kW (`DC_POWER / 1.0`).
- **Weather Stations:** 1 localized on-site weather monitoring station.

## 4. Schema Definitions

### Inverter Generation Telemetry (`Plant_X_Generation_Data.csv`)
| Column | Type | Units | Description |
| :--- | :--- | :--- | :--- |
| `DATE_TIME` | String | Timestamp | Measurement timestamp (Plant 1: `DD-MM-YYYY HH:MM`, Plant 2: `YYYY-MM-DD HH:MM:SS`) |
| `PLANT_ID` | Integer | ID | Unique identifier of the solar park |
| `SOURCE_KEY` | String | Hash ID | Unique hardware identifier for the string/central inverter |
| `DC_POWER` | Float | Raw Units | Instantaneous DC power generated by the PV array strings |
| `AC_POWER` | Float | kW | Instantaneous AC power converted and fed into the grid step-up transformer |
| `DAILY_YIELD` | Float | kWh | Cumulative daily energy generated by this inverter up to the timestamp |
| `TOTAL_YIELD` | Float | kWh | Lifetime cumulative energy generated by this inverter |

### Weather Sensor Telemetry (`Plant_X_Weather_Sensor_Data.csv`)
| Column | Type | Units | Description |
| :--- | :--- | :--- | :--- |
| `DATE_TIME` | String | Timestamp | Measurement timestamp (`YYYY-MM-DD HH:MM:SS`) |
| `PLANT_ID` | Integer | ID | Unique identifier of the solar park |
| `SOURCE_KEY` | String | Hash ID | Unique hardware identifier for the weather sensor pyranometer/thermocouple |
| `AMBIENT_TEMPERATURE` | Float | °C | Ambient outdoor dry-bulb air temperature |
| `MODULE_TEMPERATURE` | Float | °C | Back-of-module silicon cell surface temperature |
| `IRRADIATION` | Float | kW/m² | Instantaneous solar plane-of-array (POA) irradiance |

## 5. Preprocessing & Quality Assurance Protocol

1. **Timestamp Standardization:** Standardized multi-format timestamp conventions across files to ISO 8601 `YYYY-MM-DD HH:MM:SS`.
2. **Deduplication:** Filtered redundant sensor transmissions matching `(DATE_TIME, SOURCE_KEY)`.
3. **Physical Boundary Enforcement:**
   - Generation and irradiation values clamped to non-negative physical limits ($P \ge 0$, $G \ge 0$).
   - Environmental temperatures validated against reasonable physical boundaries (Ambient: -10°C to 60°C; Module: -10°C to 85°C).
4. **Energy Integration:** Calculated interval electrical energy ($E_{\text{interval}} = P_{\text{ac}} \times 0.25\text{ h}$).
5. **Missing Value Treatment:** Forward-filled minor isolated weather sensor dropouts (only 4 missing records in Plant 1) using monotonic time interpolation.
